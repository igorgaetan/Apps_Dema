🎓 Concepts DevOps illustrés dans ce projet

Ports réseau
Front :5500 | API :8080 | BD :5432 – chaque service a son propre port
API REST
Interface standardisée entre services. Les méthodes HTTP encodent l'intention (GET=lire, POST=créer…)
CORS
Sécurité navigateur : un front ne peut pas appeler un back sur un autre port sans autorisation explicite
Codes HTTP
200 OK, 201 Created, 204 No Content, 404 Not Found, 400 Bad Request
JSON
Format d'échange universel entre services. Spring Boot sérialise/désérialise automatiquement
Architecture 3 tiers
Présentation (HTML) → Logique métier (Java) → Données (PostgreSQL)
